# Kinh doanh vệ sinh kính cửa hàng – Nam đảo Phú Quốc

Dịch vụ lau kính mặt ngoài **hằng ngày** cho cửa hàng ở Nam đảo Phú Quốc. Chủ không trực tiếp làm mà thuê công nhân.

| File | Nội dung |
|---|---|
| [`KE_HOACH_KINH_DOANH.md`](./KE_HOACH_KINH_DOANH.md) | Kế hoạch kinh doanh sơ bộ: giá/m², đầu tư, vận hành, marketing, dự báo 12 tháng, rủi ro, lộ trình |
| [`tinh-gia-ve-sinh-kinh.xlsx`](./tinh-gia-ve-sinh-kinh.xlsx) | Bảng tính có công thức. Sửa ô chữ xanh, giá và lãi/lỗ tự tính lại |
| [`scripts/tao_bang_tinh.py`](./scripts/tao_bang_tinh.py) | Script tạo lại file Excel (`pip install openpyxl`) |

**Kết quả chính (giả định ban đầu):** giá vốn ≈ 2.200 đ/m²/lần, **giá bán đề xuất 3.200 đ/m²/lần**. Một cửa hàng 20 m² kính trả ≈ 1,92 triệu đ/tháng cho gói lau hằng ngày.
